# Support

Use [GitHub Issues](https://github.com/p-to-q/via/issues) for reproducible installation, validation, and rendering problems.

Include:

- Node.js version;
- the command and full concise error;
- the smallest sanitized RouteSpec that reproduces the problem;
- whether you used the CLI, Skill, or Plugin bundle.

Use [private vulnerability reporting](https://github.com/p-to-q/via/security/advisories/new) for security issues. General product discussion belongs in GitHub Discussions after it is enabled.
