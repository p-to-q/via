# via 0.3.7

via 0.3.7 corrects the relationship between the model's answer and the route map.

## What changed

- The model keeps its normal user-facing planning response: three route explanations, reasoning, tradeoffs, recommendation, and useful implementation feedback.
- The SVG is an additional interface for the same decision. It does not replace or compress the written answer.
- RouteSpec remains a lightweight display scaffold rather than a prescribed reasoning system.
- The prompt continues to encourage careful intent reading, first-principles understanding, and model judgment without imposing a long checklist.
- The evaluation guide no longer fails an answer for exceeding two sentences after the SVG; scan speed is evaluated on the visual itself.
- Product and interface documents now record Google Maps route choice, Google Earth spatial overview, and Git Tree engineering topology under this corrected contract.
- Product and interface documents distinguish their AI-interface references: ChatGPT and Codex for quiet coding UI and context; Claude Artifacts for on-demand visual assistance; via for a small RouteSpec fixture.
- via leaves host-native thinking, progress, processed panels, and reasoning summaries intact while following each host's policy for private internal reasoning.
- via is positioned as an alternative interface for the Plan-mode moment, adopting context gathering, consequential clarification, suitable reasoning depth, and planning before implementation without claiming to replace host runtime controls.

The Skill still avoids unnecessary prompt and formatting overhead. It does not remove useful analysis merely to minimize tokens.
