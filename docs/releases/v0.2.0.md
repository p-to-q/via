# via 0.2.0

The first public release.

via turns an engineering task into a Git-tree map: three routes can share checkpoints, split into unique work, take a local branch, and merge at a common proof point. Each route card shows estimated token and time ranges.

## Included

- `via-route` Agent Skill
- validated Codex Plugin bundle
- RouteSpec 0.2 JSON Schema and structural validator
- deterministic, motion-aware SVG renderer
- `via validate` and `via build` CLI commands
- trigger, topology, fake-route, proof, and CLI tests
- public Skill ecosystem and community research

## Current limits

- Token and time values are estimates supplied by the generating agent.
- Layout uses explicit columns and lanes rather than automatic graph layout.
- The Codex Plugin bundle is ready for marketplace submission but is not yet listed.
- The npm package name is reserved by availability, not yet published.
