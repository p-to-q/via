# via 0.3.0

via 0.3 makes route choice easier to read and easier to audit.

## What changed

- RouteSpec 0.3 replaces hand-entered `gates` totals with `control` nodes.
- Cards derive `checks` from decisions, proofs, boundaries, and releases on each route.
- Each new map selects three distinct colors from Codex's public blue, orange, green, pink, purple, and cyan visualization family, then persists them in RouteSpec.
- Route names carry route identity; card frames and surfaces remain neutral.
- The selector uses symmetric card geometry and a stronger Codex-composer-inspired perimeter.
- The runtime heading asks the user to choose; the actual task appears as its subtitle.

## Compatibility

RouteSpec 0.2 files must be migrated: set `schemaVersion` to `0.3`, replace the three legacy color names with any three distinct values from `blue | orange | green | pink | purple | cyan`, remove route-level `gates`, and mark meaningful graph nodes with `control: decision | proof | boundary | release`.
