# via 0.3.2

via 0.3.2 turns the post-release visual tuning into a tagged release.

## Interface

- README now points at the latest regenerated example SVG.
- The map title is model-generated; `Choose how this gets built` stays as the fixed subtitle.
- Route card shells remain neutral, while route color is reserved for graph strokes and time labels.
- Token and time now form a tighter metric block with more balanced space above and below.
- `START` and `DONE` are fixed endpoint roles; their captions are model-generated origin and achieved-state labels.

## Skill behavior

- The Skill now explicitly hints the model to write meaningful origin and destination node labels instead of generic `intent` and `ship`.
- RouteSpec documents the endpoint roles separately from the model-generated captions.
- The design system records the full visual identity: ChatGPT/Codex-native surfaces, Google Maps route choice, Git Tree topology, and structured context for human-agent decision-making.
