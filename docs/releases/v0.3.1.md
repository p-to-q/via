# via 0.3.1

via 0.3.1 refines the production surface and gives the model more room to exercise judgment.

## Interface

- Route names and card shells are neutral; time labels carry route color.
- Lane guides are longer and stronger.
- Repeated choice guidance no longer appears inside every SVG.
- Traffic-signal icons now sit before their check count, and START/DONE expose the actual starting and achieved states.
- The selector and cards now use symmetric 16 px vertical nesting.
- A tighter, heavier shadow remains fully inside the 660 px canvas.

## Skill behavior

- RouteSpec remains strict about renderability and data integrity.
- Topology preferences are no longer hard validation errors.
- Models decide whether overlap, branches, proofs, or controls are meaningful for the actual task.
- Token and time ranges are evidence-calibrated rather than selected from fixed buckets.
- Open-ended planning questions naturally produce three options, while the model remains free to decline fake alternatives and use its own task-specific judgment.
- A short intent-and-purpose reflection helps the model understand the outcome behind the literal request before it forms routes.
