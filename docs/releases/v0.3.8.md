# via 0.3.8

via 0.3.8 lets the route interface enter and leave a conversation naturally.

## What changed

- Open planning decisions still produce the familiar route comparison and map.
- After the user chooses a route, the model continues normally from that choice instead of generating another three-option map.
- A map is redrawn only when changed goals, constraints, evidence, or available options materially alter the topology.
- via becomes inactive when the work narrows to implementation, a small edit, or a factual question.
- No persistent via state or future-invocation prediction is required; the model decides from the current turn and conversation context.
- The product documents its core hypothesis: a light technical schema may help the model form clearer relationships and a more principled topology without prescribing its reasoning.
- ChatGPT, Codex, and Claude are grouped as one AI-native model-company interface reference family.
- The npm package includes the runnable Skill/CLI plus the adjacent design, architecture, agent-surface, and Skill-research documents; progressive disclosure keeps them out of normal-turn context unless needed.

## Package

```bash
npm install --global @afkv/via@0.3.8
```
