# via 0.3.6

via 0.3.6 makes the Git-tree map follow the task instead of a preferred diagram shape.

## What changed

- RouteSpec can declare per-route origins and destinations through optional `graph.terminals`.
- Routes may share their full trunk, overlap in pairs, split and rejoin locally, or begin and finish at different nodes.
- START and DONE labels now attach to their actual endpoint nodes.
- The Skill asks the model to choose topology from the work while keeping RouteSpec a display contract rather than a reasoning framework.
- The example map now demonstrates a shared trunk, two-route overlap, route-specific offsets, a dashed probe, and staggered merges.
- Validation rejects isolated nodes, duplicate connections, invalid terminal paths, and routes whose p and q are the same node.

The new terminal field is optional, so existing RouteSpec 0.3 files with one shared origin and destination continue to validate and render unchanged.

## Package

```bash
npm install --global @afkv/via@0.3.6
```

The published package includes the Skill, validator, renderer, example, core design and architecture documents, and CLI. It does not include repository-only tests, evaluation fixtures, release history, or contributor administration.
