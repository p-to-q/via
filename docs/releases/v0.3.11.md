# via 0.3.11

via 0.3.11 holds the map together on wide scripts and lets a non-English surface keep its own words.

## Fit and validate accurately

The validator now applies one corridor rule in both modes: a route edge that leaves its origin-to-destination path is rejected whether or not `graph.terminals` is declared. The renderer fits text by measured width — it shrinks type to a floor and elides only as a last resort — so wide scripts (CJK/full-width) stay inside their columns instead of overflowing or overlapping. Card labels share that protection, and the node-label budget follows the column step. The committed English example renders byte-identically.

## Keep your own interface words

RouteSpec accepts an optional `chrome` object (`subtitle`, `start`, `done`, `checks`). A non-English surface can translate the fixed interface words and pass them through; the default stays English and the brand stays English. The Skill states the rule in one line: write visible strings in the user's language, and add `chrome` only when it is not English.

## Show the map where it can be seen

The Skill now defers to the surface: show the map inline where the chat renders images, through the host's own preview where it has one, otherwise by its file path or a local `localhost` URL. A text-only surface shows the path, not the image.
